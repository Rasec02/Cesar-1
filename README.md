Este proyecto implementa en Java una lista doblemente enlazada (DLinkedList) y resuelve tres ejercicios básicos sobre ella: eliminar elementos repetidos, rotar una posición a la derecha y concatenar dos listas. Se trabajó con nodos que tienen referencia al siguiente (next) y al anterior (prev), respetando la interfaz IList<E> propuesta en clase. El primer ejercicio recorre la lista y elimina los nodos cuyos valores ya aparecieron antes. El segundo mueve el último nodo al inicio, desplazando el resto una posición. El tercero enlaza el final de la primera lista con el inicio de la segunda. El proyecto incluye las clases Node, DNode, IList, DLinkedList y un Main con casos de prueba positivos y negativos para verificar su correcto funcionamiento.
